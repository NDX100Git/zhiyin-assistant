# 智印助手 · 安装说明（评委 / 演示版）

## 兼容系统

- Android 8.0 及以上（API 26+）
- 需要联网（连接部署后端的电脑或服务器）

## 安装步骤

1. 把 `智印助手.apk` 传到手机（微信文件传输助手、数据线均可）。
2. 用手机文件管理器点击 APK。
3. 如果提示「禁止安装未知来源应用」，点击「设置」→ 允许当前文件管理器/浏览器安装未知应用。
4. 返回安装界面，点击「安装」。
5. 安装完成后桌面会出现「智印助手」图标。

首次打开如提示网络权限，请选择「允许」。

## 演示前网络准备（重要）

演示版需要手机能访问后端电脑：

1. 手机与电脑连接同一个 Wi-Fi。
2. 电脑启动后端（监听 `0.0.0.0:8000`）。
3. 电脑用管理员 PowerShell 放行 8000 端口：

```powershell
netsh advfirewall firewall add rule name="ZhiYin API 8000" dir=in action=allow protocol=TCP localport=8000
```

4. 手机浏览器访问 `http://电脑IP:8000/api/health`，能看到 `{"code":0,...}` 即连通。

## 60 秒演示流程

1. 打开 App，首页能看到排队人数、预计等待、收单状态与公告。
2. 点底部「下单」。
3. 点「载入示例论文（演示兜底）」（最稳，避免真机选文件差异）。
4. 等待几秒，出现「基础方案」，可直接调单双面/颜色/版式/份数。
5. 想看 AI 能力，点「开始 AI 体检」：出现问题清单（缺目录、参考文献缺页码等）。
6. 点「确认下单」，得到订单号与取件码。
7. 点「模拟支付」，订单进入排队。
8. 老师端打开 `http://电脑IP:5174`，登录后完成打印并核销，学生端「我的」里状态同步为已完成。

## 常见问题

| 问题 | 处理 |
|---|---|
| 打开 App 提示网络错误 | 检查手机与电脑同一 Wi-Fi；确认 `.env.production` 的 API 地址是电脑 IP；确认后端与防火墙 |
| 选择文档没有反应 | 使用「载入示例论文」；或在老师/开发同学协助下确认 App 端 `plus.io.chooseFile` 支持情况 |
| AI 体检很久没结果 | 点体检才会调用 AI；基础方案不依赖 AI。网络慢时稍等或重试 |
| 拍照识别无结果 | 确认图片清晰、有文字；OCR 依赖后端大模型 |
| 取件码核销失败 | 确认订单状态为「待取件」，取件码输入正确（如 A-01） |
